# moss

[English](README.md) | Русский

Пространство для заметок и данных, в котором ты работаешь вместе со своим AI-агентом.

У тебя есть папка обычных файлов: Markdown, CSV, PDF, Excel, Word. moss показывает её как страницы, таблицы и графики, как в Notion. Твой агент (Claude Code, Codex или локальная модель) работает в той же папке. Каждая его правка видна прямо на странице, и любую можно отменить.

Cursor и T3 Code сделали это для кода. moss делает то же для заметок и личных данных.

> Пока это идея. Кода ещё нет.

## Зачем

Notion хранит данные на своих серверах и не даёт подключить свой AI.

Obsidian хранит файлы у тебя на диске, но у обычного markdown мало структуры. Для таблиц и графиков нужны плагины.

Claude Code можно натравить на папку Obsidian уже сейчас. Но тогда его правки ты читаешь как diff текста в терминале, и без тебя ничего не происходит.

## Как это работает

Каждая страница — markdown-файл. В шапке лежат свойства страницы, ниже её текст:

```markdown
---
type: Пост
status: Запланирован
publish: 2026-11-13 10:00
---
apps change. models change. your data stays.
```

`type` даёт странице поля. Его можно добавить в любой момент. Сначала пишешь обычные заметки, а когда появляется закономерность, превращаешь их в записи с типом.

Чтобы показать на странице другие страницы, добавь блок `view`:

````markdown
```view
show: Пост
where: status != Архив
layout: table
```
````

В moss этот блок становится живой таблицей, её можно править мышкой. В любом другом редакторе это короткий блок кода, который всё равно можно прочитать.

PDF, Excel и Word открываются в своих редакторах внутри moss и сохраняются в своих форматах. Любой файл можно положить на страницу, и он покажет превью.

Само пространство — обычная папка:

```
~/moss/
  AGENTS.md          правила для агентов в этом пространстве
  Контент/
    Посты.md
    посты/*.md       один пост — один файл
  Здоровье/
    еда.csv
  .moss/             поисковый индекс, история, типы, настройки агентов
```

Если удалить `.moss/`, пропадут история и индекс. Заметки останутся.

## Правила

1. Твои данные — обычные файлы у тебя на диске.
2. У тебя и у агента одинаковые инструменты. Всё, что собрал агент, ты можешь собрать или поменять руками.
3. Правки агента появляются прямо на странице, у каждой есть «Принять» и «Отменить».
4. Агенты могут работать по расписанию. Если им нужно твоё решение, они оставляют вопрос в Inbox.
5. Подходит любой агент. moss запускает официальный CLI Claude Code или Codex, поэтому работает твоя собственная подписка.

## План

1. Markdown-страницы, типы и виды.
2. Тред с агентом, где видны правки и есть отмена.
3. Агенты по расписанию и Inbox.
4. PDF и CSV, потом Excel и Word.
5. Синхронизация, приложение для телефона, self-hosting для команд.

Локально moss будет бесплатным. Платными планируем сделать AI на наших серверах, синхронизацию и сервер, на котором агенты работают, пока ноутбук выключен.
