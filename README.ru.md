# moss

[English](README.md) | Русский

**Твоя папка файлов. Твой агент. Всё, что он делает, видно и откатывается.**

moss — открытое local-first рабочее пространство для заметок и личных данных, сделанное под AI-агентов. Ты хранишь папку обычных файлов: Markdown, CSV, PDF, Word, Excel. moss показывает её как рабочее пространство со страницами, таблицами и графиками, похоже на Notion. Агенты, которыми ты уже пользуешься, например Claude Code, Codex или локальная модель, работают в той же папке вместе с тобой.

Коротко: Cursor и T3 Code сделали это для кода. moss делает это для заметок и данных.

> Статус: стадия идеи. Пока ничего не работает. Этот README описывает, что мы собираемся сделать.

## Зачем

- Notion закрыт. В него нельзя привести свой AI, а данные лежат на чужом сервере.
- Obsidian хранит твои файлы, но у папки markdown мало структуры. Для таблиц, графиков и типизированных записей нужны плагины.
- Трекеры еды, денег или привычек держат данные каждый в своём приложении. Попросить AI проанализировать всё вместе нельзя.
- Obsidian плюс Claude Code в терминале уже работает, но правки агента видны как сырой diff текста. Ничего не работает в фоне, и ничто понятно не спрашивает разрешения.

## Что это

### Для человека

- **Home** показывает, что агенты сделали за ночь, что ждёт тебя, и одну строку, чтобы записать или спросить что угодно.
- **Страница** — редактор как в Notion поверх `.md`-файла. Отдельных режимов редактирования и просмотра нет. Рядом со страницей можно открыть агента, и он видит ту же страницу, что и ты.
- **Тред** — полный разговор с агентом. Видно, что агент прочитал, что и когда поменял, и есть чекпоинты, к которым можно вернуться.
- **Inbox** собирает вопросы и запросы разрешений от агентов, например «можно прочитать Сон?» или «добавить вид Топ постов?».

### Для агента

Агент видит обычную папку и несколько договорённостей:

```
~/moss/
  AGENTS.md                 как устроено пространство, правила, глоссарий
  Контент/
    Посты.md                страница с живым видом
    посты/
      P-43 apps change.md   один пост — один файл
  Здоровье/
    Еда.md
    еда.csv                 сотни мелких записей в одной таблице
    анализы-ноябрь.pdf
  .moss/
    index.db                поиск, поля, история (можно пересобрать)
    types/пост.yaml         поля типа «Пост»
    skills/x-stats/         SKILL.md и скрипт
    agents/writer.md        роль, доступы, расписание
```

Агенты читают и пишут файлы. Для запросов вроде «все черновики» и для истории у них есть `moss` CLI или MCP-сервер. Так агенты уже умеют работать в репозиториях с кодом.

## Как устроены страницы

Всё является страницей. Страница — это markdown-файл. В шапке (frontmatter) лежат свойства, в теле лежат блоки.

```markdown
---
type: Пост
status: Запланирован
publish: 2026-11-13 10:00
idea: "[[P-31 угол запуска]]"
views: 0
---
apps change. models change. your data stays.
```

Тип — это ярлык с полями, а не папка. Каждый файл с `type: Пост` попадает в виды постов, где бы он ни лежал. Тип можно добавить позже: сначала пишешь обычные заметки, а когда появляется закономерность, ты или агент превращаете их в записи с типом.

Страница может показывать данные других страниц через блок `view`. Так же делают Obsidian Bases, Dataview и Mermaid:

````markdown
# Посты

```view
show: Пост
where: status != Архив
layout: table
columns: [status, format, publish, views]
```
````

В moss этот блок — живая таблица, которую можно править мышкой. В любом другом редакторе это читаемый блок кода.

На странице лежат блоки трёх видов:

1. Текст: абзацы, заголовки, списки, задачи, цитаты, код.
2. Файлы: картинки, PDF, Excel, Word, аудио. Каждый показывает превью и открывается в своём редакторе внутри moss.
3. Виды: таблица, доска, календарь, график или одно число поверх других страниц и строк CSV.

## Правила

1. Твои данные — обычные файлы в папке. Если удалить `.moss/`, пропадут история и кеш, но не данные.
2. У человека и агента одни и те же действия. У агента нет блоков, которых ты не можешь добавить из меню `/`, и всё, что сделал агент, можно поправить руками.
3. Правки агента видны на самой странице: новый текст подсвечен, у изменённой цифры видно старое значение, у каждой правки есть «Принять» и «Отменить».
4. Агенты работают в фоне, по расписанию или по событиям. Когда им что-то нужно, они пишут в Inbox и не блокируют тебя.
5. Внешние данные, например статистика постов из X, приходят через Sources: маленькие задачи по расписанию, которые пишут в файлы. Виды только читают.
6. Подходит любой агент. moss запускает официальный CLI Claude Code, Codex или локальную модель, так что ты пользуешься своей подпиской.

## Файлы

| Формат | В moss |
|---|---|
| `.md` | полный редактор страниц |
| `.csv` | редактор таблиц |
| `.pdf` | просмотр с выделениями. Агент может достать из него записи со ссылкой на страницу |
| картинки, аудио, видео | просмотр, плюс OCR и расшифровка |
| `.xlsx` | редактор таблиц. Правки агента подсвечены по ячейкам |
| `.docx` | редактор документов. Правки агента приходят как исправления Word (track changes) |

Каждый файл сохраняется в своём формате, так что его по-прежнему можно открыть в Excel, Word или Obsidian.

## Для кого

Первые пользователи — люди, которые каждый день работают с Claude Code или Codex и ведут заметки в Obsidian или Notion. Что они могут собрать, просто попросив агента:

- контент-план для X со статистикой постов, которая обновляется каждое утро;
- дневник еды и веса по фото и сообщениям;
- список книг, трекер поиска работы, расходы из банковских выписок, карточки из заметок.

## Как зарабатывать

- Локально всё бесплатно и полностью работает.
- Платный инференс для тех, у кого нет подписки или кто не хочет тратить свои лимиты.
- Платная синхронизация и хостинг, чтобы ничего не настраивать самому.
- Платная машина, которая работает всегда: на ней крутятся агенты и Sources, пока ноутбук спит.
- Self-hosting для команд и компаний, в том числе с локальными моделями.

## План

1. Папка markdown-файлов, редактор страниц, типы и блоки `view` поверх frontmatter.
2. Тред с агентом: видимые правки, история и откат через Claude Code и Codex.
3. Sources и фоновые агенты, Inbox.
4. CSV и PDF, потом Excel и Word.
5. Синхронизация, быстрый захват с телефона, self-hosting для команд.

moss — рабочее название.
